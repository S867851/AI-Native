# 平台外部服务与付费依赖清单

日期：2026-10-25。范围：当前 JeecgBoot v3.9.5 + FlowGram 测试实例。

## 依据与边界

- 知识库：Vault 未检索到本平台外部服务或采购记录，不据此推断已经购买任何服务。
- 当前检查：服务器 `sys_permission` 中所有未删除的目录/页面记录、当前前端源码和构建环境配置、后端组件依赖、生产上传模式，以及官方积木产品资料。
- 全量菜单快照：[菜单审计 TSV](JeecgBoot-菜单审计-2026-10-25.tsv)。包含隐藏路由和示例，不代表每条都在当前用户侧边栏显示。
- 本文列出已识别的外部依赖入口和收费候选，并区分页面管理与实际调用。没有逐一发起生成、短信等可能计费的操作，没有读取账单或导出密钥。
- 用户可在数据库、模型配置、MCP配置、流程和数据源内填入任意动态地址；静态代码与菜单审计不能穷尽这些地址背后的供应商、套餐或实际费用。最终收费以选定供应商和合同为准。
- 本次仅盘点，没有隐藏菜单、关闭服务或删除代码。

## B. 需要模型/能力服务，费用取决于供应商的页面

浏览列表和修改配置本身通常只调用本机后端；下表的依赖主要在“生成、识别、检索、执行”等操作触发。自部署模型也有算力与运维成本，不等于必须向第三方购买 API。

| 页面 | 当前菜单路由 | 实际执行依赖 | 费用/状态判断 |
|---|---|---|---|
| AI模型配置 | `/super/airag/aimodel/AiModelList` | 选择的模型供应商或自建模型服务 | 配置页不是收费页；实际模型调用按接入方案判断 |
| AI聊天 | `/super/airag/aiapp/chat/AiChat` | 对话模型，可进一步调用知识库/工具 | 商业 API 可能计费；本次未做收费调用 |
| AI应用管理 | `/super/airag/aiapp/AiAppList` | 应用实际运行所选模型、流程及工具 | 列表/编辑不是必须付费；运行按能力计费 |
| 应用门户 | `/app/portal` | 门户中选用的 AI 应用 | 同上，不应把整个门户归为收费组件 |
| AI流程设计 | `/process/list/airag` | 流程节点选择的模型、HTTP、搜索、MCP等 | 基础画布和控制节点不必购买模型；外部调用需逐节点判断 |
| AI知识库 | `/super/airag/aiknowledge/AiKnowledgeBaseList` | 向量嵌入模型、向量存储；问答还需对话模型，部分文档需解析服务 | 本机向量库存储已部署；模型/解析依赖不因此自动可用 |
| MCP配置 | `/super/airag/aimcp/AiragMcpList` | 配置的 MCP 或插件服务 | 可本地运行，也可连接收费供应商；必须按具体工具审核 |
| AI提示词 / AI评估器 | `/super/airag/aiprompts`、`/super/airag/experiment` | 评估/调试时使用的模型或评估服务 | 提示词保存不要求外部付费；实际评估可能消耗模型额度 |
| OCR识别 | `/ai/ocr` | 图片分析/识别能力 | 本地模板管理和真正识别要分开；识别供应商/模型及费用待配置核验 |
| Ai海报 | `/airag/aiposter/AiPoster` | 图像生成模型 | 实际生成需可用模型；示例图还依赖外部资源 |

| AI语音 | `/airag/aivoice` | 语音生成服务 | 该页面包含文字生成语音功能，不能直接当作用户需求中的录音转逐字稿已实现 |
| AI视频 | `/airag/aivideo` | 视频生成服务 | 实际生成需服务；资费和配额待确认 |
| AI换衣 | `/airag/aicloth` | 图像生成/编辑服务 | 同上；示例素材含外部 OSS 图片 |

| FlowGram 工作流 | `/flowgram/workspace` | 基础画布、保存、Start→End由自建服务提供；模型/HTTP/MCP节点按配置调用 | 已验证的基础流程无需第三方模型 API；未来每类外部能力分别审核 |

## E. 当前未发现必须购买外部服务的核心页面

用户、角色、菜单、部门、字典、基础租户配置、站内消息、日志、定时任务、本机Redis/性能/SQL监控、普通CRUD、ECharts基础图表、FlowGram基础画布与文本回传流程，都不能仅因属于JeecgBoot而归类为“付费页”。其中用户/租户/消息页面的可选短信、第三方同步、邮件等操作仍按D表判断。

## 建议的裁剪顺序（建议，不是已确认执行清单）

1. 优先挑出官网、文档示例、厂商云端大屏案例及无关组件示例；它们与目标Agent编排业务关联较弱。
2. 积木报表、ChatBI、大屏和仪表盘单独确认是否保留；若不需要，再连同菜单、后端依赖和接口一起裁剪。
3. 海报、写作、视频、换衣、简历、语音生成等非当前核心页面可作为候选；注意语音生成不等于录音转写。
4. 保留模型、知识库、MCP、FlowGram与权限基础能力，它们与最初需求直接相关。对这些页面控制具体供应商和节点依赖，而不是整体删除。
5. 单独决定预览/文档服务、短信、地图、第三方登录及协作平台接入是否需要。最终按确认后的保留/删除清单实施。
